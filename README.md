# 🎮 The West

1인칭 슈팅 롤플레잉 VR 게임  
플레이어는 은퇴를 앞둔 **보안관**이 되어, 친구의 죽음을 파헤치고 **범인을 추적**한다.

---

# 🧭 게임 개요

- 장르: 1인칭 슈팅 FPS + 롤플레잉
- 배경: 미국 서부 개척 시대
- 목표: 친구를 살해한 범인을 찾아내고 복수에 성공하라

---

#🎬 스토리라인

오랜 친구인 총잡이의 사망 소식을 들은 은퇴 직전의 보안관은  
마을을 봉쇄하고 사건의 진실을 추적한다.

- 마을 곳곳을 수색하고 단서를 수집
- NPC들과의 대화를 통해 퀘스트 수행
- 범인과의 결투를 통한 정의 구현

---

## 🗺️ 게임 플레이 특징

- **ARPG** 스타일 탐험
- NPC와의 대화로 스토리 진행 및 단서 획득
- **오브젝트 상호작용**: 쓰레기통 뒤지기, 단서 수집 등
